# Django-React-Social-Media

A full-stack social media web application built using Django REST Framework and React. This project includes user authentication, profile management, posts, likes, comments, and API-based frontend-backend integration.

## Features

- User registration and login
- JWT-based authentication
- Create, edit, and delete posts
- Like and comment system
- User profile management
- React frontend with API integration
- Django REST API backend

## Tech Stack

**Frontend:** React, JavaScript, Axios, CSS  
**Backend:** Django, Django REST Framework  
**Database:** SQLite / PostgreSQL  
**Authentication:** JWT
